You are given a list of short thematic labels, each independently assigned to
one observation about how a software engineer works. Because they were
generated without shared vocabulary, many labels name the same area in
different words.

Identify the set of canonical themes that covers the whole list. Each theme
names a single, narrow concern at the right altitude: specific enough to route
a task to one topic, not so broad that unrelated concerns share a theme. Merge
only labels that are genuinely the same concern; keep distinct concerns
separate even when adjacent. Let the data decide how many themes there are —
there is no target count, floor, or ceiling.

Print each theme on its own line, prefixed with `THEME: `. Output nothing else
— no preamble, no numbering, no blank lines.
