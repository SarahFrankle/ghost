You are given a list of short thematic labels, each independently assigned to
one observation about how a software engineer works. Because they were
generated without shared vocabulary, many labels name the same area in
different words.

Identify 15–25 canonical themes that cover the whole list. Each theme names a
distinct area at the right altitude: specific enough to be meaningful, general
enough that many labels map to it. When in doubt, merge.

Print each theme on its own line, prefixed with `THEME: `. Output nothing else
— no preamble, no numbering, no blank lines.

15–25 is a hard constraint. If you exceed 25 you are not consolidating
aggressively enough — thematically adjacent labels should share a theme.
